FeatureMAP is a feature-centric, metabolic network-guided framework for interpreting untargeted LC-MS metabolomics data. It integrates feature-to-metabolite annotation, cutoff-free feature weighting, network refinement, and module detection to identify dysregulated metabolic modules. Outputs include refined annotations, statistically supported modules, and LLM-assisted functional interpretation.
