PhenoMAP connects phenotypes, metabolomics studies, co-regulated metabolite modules, and individual metabolites in a phenotype-centered knowledge graph. The web platform provides entity search, path queries, module enrichment, and PhenoMAP Chat for exploring connections and asking questions with cited sources.
